تطبيق جايك للآيفون
==================

مبني بـCapacitor — نفس أسلوب تطبيق امواج.
الواجهة محزومة جوّا التطبيق (مجلد www) مو تنفتح من الموقع،
لأن أبل ترفض التطبيق اللي مجرد موقع بغلاف.


كل ما تعدّل الموقع وتريد التعديل يوصل للآيفون:
----------------------------------------------
  1. node build-www.js      ← ينسخ صفحات الموقع ويجهّزها
  2. git add . && git commit && git push
  3. Codemagic يبني لحاله ويرفع لـTestFlight

⚠️ تعديل الموقع ما يوصل للآيفون لحاله — لازم بناء جديد.
   (بالأندرويد يوصل فوراً لأن التطبيق يفتح الموقع مباشرة)


الملفات المهمة
--------------
  build-www.js          يجهّز ملفات التطبيق من صفحات الموقع
  capacitor.config.json اسم التطبيق والألوان
  codemagic.yaml        إعدادات البناء على الماك السحابي
  www/                  ملفات التطبيق — تتولّد، لا تعدّلها بيدك


اسم الحزمة:  com.jayak.app   (نفس الأندرويد)

التطبيق للآيفون فقط (TARGETED_DEVICE_FAMILY = "1").
لو خليناه يدعم الآيباد، أبل تطلب صور شاشة لآيباد ١٣ إنش قبل
ما تقبل الرفع — وماكو عندنا آيباد، وتمطيط صور الآيفون يطلع بشع.
